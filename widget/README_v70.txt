Tears Widget v70 — реакция на отдельные пожертвования

Основа: графика и утверждённая жидкость v69. Все файлы из assets/ сохранены без изменений.

Новое:
- Каждый донат увеличивает текущую сумму и автоматически запускает анимацию.
- Приём событий через window.TearsWidget.triggerDonation(amount, donorName).
- Альтернативно: CustomEvent "tears:donation" и postMessage с type="tears:donation".
- Отображается краткое уведомление с именем отправителя и суммой.
- Поверхность воды получает короткую волну-импульс.
- Внутри жидкости появляется всплеск пузырьков и искр, обрезанный по внутренней маске колбы.
- Есть три уровня по сумме: небольшой (< 500 ₽), средний (500–1 999 ₽), крупный (от 2 000 ₽).
- Крупный донат вызывает более широкий всплеск, больше пузырьков и яркую вспышку.
- Поддерживается необязательный уникальный id события: повторно присланный донат с тем же id не будет начислен дважды.
- Прогресс сбора пересчитывается, а жидкость плавно поднимается к новому уровню.
- Если цель достигнута, включается существующий эффект 100%.

Как отправить событие из другого скрипта:
window.TearsWidget.triggerDonation(500, 'Имя отправителя', 'donation-unique-id');

Через CustomEvent:
window.dispatchEvent(new CustomEvent('tears:donation', {
  detail: { amount: 500, username: 'Имя отправителя', id: 'donation-unique-id' }
}));

Через postMessage:
window.postMessage({
  type: 'tears:donation',
  amount: 500,
  username: 'Имя отправителя',
  id: 'donation-unique-id'
}, '*');

Проверка:
1. Открой Проверка_заполнения.html.
2. Введи имя отправителя.
3. Нажми +100 ₽, +500 ₽, +2 000 ₽ и +5 000 ₽.
4. Проверь, что текущая сумма увеличивается, уведомление появляется, поверхность даёт импульс, внутри жидкости видны пузырьки и искры.
5. Крупные пожертвования должны создавать более заметный всплеск.
6. Проверь переход суммы через 100%: жидкость останавливается на максимуме, а праздничная анимация достижения цели включается.

Пороги по умолчанию:
- небольшой: до 499 ₽;
- средний: от 500 ₽;
- крупный: от 2 000 ₽.
Пороги можно изменить в widget.html в константах MEDIUM_DONATION и LARGE_DONATION.

Важно по интеграции:
- В v70 подготовлен входной интерфейс для событий донатов, но прямое подключение к DonationAlerts ещё не настроено.
- Источник, который получает уведомления DonationAlerts, должен передавать их в виджет через один из указанных выше методов.
- Графика, маски, стекло и ободок не менялись.

Установка:
1. Сохрани v69 как резервную копию.
2. Создай папку Tears_v70.
3. Распакуй весь архив целиком, сохранив папку assets.
4. Открой Проверка_заполнения.html и проверь тестовые донаты.
5. После проверки подключи widget.html в OBS.
6. Для реального подключения подай события от своего источника донатов через documented API.
