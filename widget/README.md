# Донат-бар «Слёзы»

Страница виджета для OBS находится в `index.html`.

## Быстрый тест без подключения Cloudflare

Открой `index.html?current=7500&goal=10000` — тестовые значения 7 500 ₽ и 10 000 ₽.

## Подключение DonationAlerts

После публикации Cloudflare Worker:
- `../config.js` должен содержать URL Worker;
- `../da-cloudflare.js` подключает виджет к публичному live-каналу Worker;
- `runtime.js` обновляет сумму и уровень жидкости при поступлении события.

Начальная сумма, цель и валюта задаются через панель владельца `../admin.html`. Если Worker не настроен, виджет остаётся в демонстрационном режиме.

## OBS

Добавь источник «Браузер» и укажи URL страницы `/charmeeck-tears/widget/`. Размер: 1774 × 887. Также можно использовать локальный файл `widget/index.html`, но для реальных донатов страница должна быть загружена через GitHub Pages.

## Безопасность

OAuth Client Secret, access/refresh tokens и секреты Worker нельзя помещать в эту папку, URL виджета или публичные файлы GitHub. Они хранятся только в Cloudflare Secrets и зашифрованной D1 базе.
