# Донат-бар «Слёзы» — v70

Основная страница для OBS: `index.html`.
Автономная проверка внешнего вида и реакций: `test.html`.

В production-виджет перенесена утверждённая версия v70: прозрачные слои колбы,
маска уровня жидкости, анимация пузырьков, эффект завершения сбора и три уровня
реакции на донат (до 499 ₽, 500–1 999 ₽ и от 2 000 ₽).

После настройки Cloudflare Worker страница загружает начальную сумму, цель и
валюту через `../config.js` и `../da-cloudflare.js`. OAuth-секреты и токены
в репозитории не хранятся.

Для OBS используй:
`https://charmeeck.github.io/charmeeck-tears/widget/`
Размер источника: 1774 × 887.
