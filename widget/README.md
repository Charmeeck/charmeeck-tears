# Донат-бар «Слёзы»

Статический OBS Browser Source.

## Быстрый тест
Откройте `index.html?current=7500&goal=10000` — сумма 7 500 ₽ при цели 10 000 ₽.

## OBS
Добавьте источник «Браузер», включите «Локальный файл» и укажите `widget/index.html`.
Размер: 1920 × 960 (соотношение 1774:887). Папка `assets` должна лежать рядом с HTML в каталоге `widget`.

## Параметры URL
- `current` — текущая сумма (по умолчанию 3750)
- `goal` — цель (по умолчанию 10000)

## Статус интеграции
Это демо с параметрами URL. Реальная OAuth-авторизация DonationAlerts, серверное хранение токенов, приём событий и персональные ссылки пока не реализованы. Их нельзя безопасно реализовать только средствами GitHub Pages: для серверной части потребуется отдельный HTTPS backend. Не публикуйте OAuth client secret или токены в этом репозитории.
