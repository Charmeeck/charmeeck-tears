# CharMeeck Tears

Independent project for the animated OBS donation bar «Слёзы».

- Main page: GitHub Pages
- Demo widget: `/widget/`
- Test values: `/widget/?current=7500&goal=10000`

## Publish
GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Integration status
Currently static UI/demo only. DonationAlerts OAuth and realtime event processing require a secure backend. Never put OAuth secrets or access tokens in this repository.

The existing «Кровь» widget is not included or modified.
